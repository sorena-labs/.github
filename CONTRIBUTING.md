# Contributing

Everything in Sorena Labs repos is made and signed by people on the team.

- Commit and push from your own GitHub account, with your real name and your GitHub noreply email.
- Never add an AI tool as a co-author, and never add session links or "generated with" lines.
- Never name an AI tool in a commit message, branch name, pull request title or description.

The Authorship check runs on every push and pull request and fails if it finds one. On public repos GitHub also refuses the push.
