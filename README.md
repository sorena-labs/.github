# .github

Organisation-wide files for Sorena Labs. This repo must stay public for GitHub to use them.

- `profile/README.md` is the public profile on github.com/sorena-labs.
- `pull_request_template.md` is the default pull request checklist for every repo in the org that doesn't have its own.
- Other community files added here (issue templates, CONTRIBUTING.md, SECURITY.md) become defaults the same way.
